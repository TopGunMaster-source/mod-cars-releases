# Mod Cars for Burnout Paradise Remastered

Extra cars for Burnout Paradise Remastered (PC, EA app or Steam): a **Mod Cars** row in the junkyard car
picker with Sponsor Cars, Dev Cars and Traffic Cars, plus a **DLC Cars** row. No stock car is replaced, and
every car is owned automatically, with no save editing.

**[Download the latest release](https://github.com/TopGunMaster-source/mod-cars-releases/releases/latest)**

## Which file do I need?

| File | For |
|---|---|
| **Mod Cars Manager 2.0.1 Setup.exe** | Most players. A Windows app that sets up the mod loader and Protection, installs the car packs safely with undo, and adds paint, colours, boost and hover per car. |
| **Mod Cars Pack v1.5.1.zip** | Doing it by hand: the menu files, ModCarsKit and the 3 car packs. Instructions are in its README.txt. |

## Requirements

- **Protection** by matty-ross ([bpr-mods-repository](https://github.com/matty-ross/bpr-mods-repository)): it
  shows mod cars to other players online as stock cars. Mod Cars stays off without it. The Manager installs it
  for you.
- Bo98's mod loader (the Manager installs it too).

## Install with the Manager

1. Close the game.
2. Run **Mod Cars Manager 2.0.1 Setup.exe**. Windows may warn because the installer isn't code-signed: click
   **More info**, then **Run anyway**.
3. In the app's **Setup** tab, click **Get the official files** if anything is missing.
4. In **Car packs**, click **Install...** on each pack.
5. Start the game, go to a junkyard, and pick **Mod Cars**.
